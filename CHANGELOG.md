# Changelog

## [0.2.1] - 2026-06-01
### Added
- Added an MIT License and package license metadata.

## [0.2.0] - 2026-05-31
### Added
- Added `pyproject.toml` packaging metadata with an `epubtopdf` console command.
- Added `--input-dir` and `--output-dir` aliases for selecting source and destination folders.
- Added tqdm progress reporting for CLI batch conversions.

### Changed
- Updated runtime dependencies to include tqdm.

## [0.1.0] - 2026-05-31
### Added
- Added a Python CLI for converting all EPUB files from an input folder into PDF files in an output folder.
- Documented setup and usage for the converter.
